# Prior Art Check

## Adjacent projects and why they differ

1. Dasdaq — reconstructs real dreams into tradable assets.
   - Focus: dream capture and market representation.
   - Difference: it preserves real experience rather than intentionally fabricating false personal memories.

2. Engram — cryptographic proof that AI memories are real and untampered.
   - Focus: verifiable memory integrity and anti-hallucination.
   - Difference: it seeks to prove authenticity; this project intentionally creates explainable falsehoods.

3. Sim Francisco — synthetic populations for civic simulation.
   - Focus: large synthetic social worlds.
   - Difference: it generates a population, not a single emotionally coherent false autobiographical self.

4. QVP (Quadrant Vacancy Prompting) — concept-map prompting that pushes outputs away from obvious interpretations.
   - Focus: non-standard generation through prompt design.
   - Difference: it does not target autobiographical fabrication or personal memory gaps.

## Conclusion

The combination of fabricated personal memory + explainable rationale + local-first privacy + era-matched autobiographical visualization remains a distinct design space. The project should still be described as a narrow and testable exploration rather than a proven-unprecedented invention until more formal search results are recorded.
